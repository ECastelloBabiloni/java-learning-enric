# Objetivo de empleabilidad

Este proyecto no busca solo aprender sintaxis de Java. El objetivo es llegar a DAM y, despues, al primer empleo junior con fundamentos, proyectos explicables y habitos de aprendizaje sostenibles.

## Perfil que queremos construir

- Fundamentos tecnicos: Java, programacion orientada a objetos, estructuras de datos, bases de datos, sistemas y Git.
- Resolucion de problemas: entender el problema, dividirlo en partes, probar y revisar la solucion.
- Uso responsable de IA: usarla para aprender, contrastar y acelerar tareas; nunca copiar una solucion que no se pueda explicar.
- Criterio y contexto: saber para que sirve el programa, quien lo usa y por que una solucion es adecuada.
- Proyectos reales y explicables: poder contar que hace cada proyecto, decisiones tomadas, errores encontrados y como se resolvieron.
- Comunicacion y trabajo en equipo: hacer preguntas, explicar decisiones y aceptar revision.
- Ingles tecnico practico: comprender documentacion y poder comunicar lo esencial.
- Aprendizaje continuo: curiosidad, adaptacion y constancia sin perseguir cada moda tecnologica.

## Como aplicarlo al aprendizaje

- Cada bloque de sintaxis debe terminar en un ejercicio o una mejora de proyecto propia.
- Antes de recibir una solucion, intentar razonar y escribir una primera version cuando el concepto ya sea conocido.
- Las explicaciones de conceptos nuevos deben incluir proposito, ubicacion en el codigo y comportamiento esperado.
- Mantener proyectos pequenos en Git con commits que expliquen el cambio realizado.
- Priorizar comprender y explicar antes que producir mucho codigo rapido.

## Idea clave

El objetivo no es ser experto en todas las herramientas. Es tener una base fuerte, aprender con autonomia, usar IA con juicio y demostrarlo mediante proyectos.

## Plan escalado

### Etapa 0: inicio de DAM

Construir una aplicacion limpia de inventario en consola. Debe crear productos, buscar por nombre, mostrar datos y gestionar productos no encontrados.

Refuerza: objetos, arrays, null, Scanner, lectura de codigo y Git.

### Etapa 1: constructor fiable

Ser capaz de resolver programas de consola sencillos sin bloqueo inicial.

- Separar un enunciado en entradas, calculos, condiciones y salida.
- Crear clases con atributos privados, constructor, getters y metodos.
- Leer errores, plantear hipotesis y probar correcciones.
- Crear commits claros y explicar un programa propio en dos minutos.

Refuerza: Java, logica, autonomia, comunicacion y Git.

### Etapa 2: datos persistentes

Pasar de arrays temporales a una base de datos.

- Disenar tablas para productos, proveedores y pedidos.
- Entender claves primarias y relaciones.
- Usar SQL para crear, consultar, modificar y borrar datos.
- Conectar una aplicacion Java sencilla a esos datos.

Refuerza: SQL, modelado, contexto de negocio y proyectos reales.

### Etapa 3: proyecto intermedio

Crear una aplicacion pequena pero completa, como una evolucion del inventario o de la calculadora de masa de pizza.

- Separar las clases por responsabilidad.
- Guardar datos en una base de datos.
- Validar entradas y mostrar mensajes claros.
- Documentar el problema, uso y aprendizajes en un README.
- Mantener un historial de commits comprensible.

Refuerza: arquitectura, calidad, documentacion y explicacion de decisiones.

### Etapa 4: preparacion para practicas y primer empleo

Tener dos o tres proyectos que se puedan defender en una entrevista.

Para cada proyecto, poder explicar el problema, tecnologias, decisiones, errores resueltos y mejoras futuras.

Refuerza: entrevista, pensamiento critico, comunicacion e IA responsable.

## Habitos recurrentes

- Cada semana: un ejercicio resuelto de forma autonoma.
- Cada dos semanas: una mejora visible en un proyecto.
- Cada mes: explicar un programa como en una entrevista.
- Ingles tecnico: documentacion corta, terminos y mensajes de error.
- IA: pedir pistas, revisiones y explicaciones; no presentar codigo que no se pueda defender.
